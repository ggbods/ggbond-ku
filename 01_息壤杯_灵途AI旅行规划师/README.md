# 灵途 · AI 旅行规划师（息壤杯参赛作品）

## 项目简介

比赛主题是 AI 应用，我做了这个网站：用户输入目的地、预算、天数，AI 自动生成整份攻略——每天上午下午晚上去哪、吃什么、交通怎么安排、预算怎么花，一条龙排好，还能换风格重排（经典 / 悠闲 / 紧凑）。

除了核心的攻略生成，还做了这些功能：

- **AI 推荐目的地**：不知道去哪时，答几道偏好题，AI 给你推荐合适城市
- **多方案对比**：一次生成 2~3 套方案，表格对比后选一个
- **攻略库**：生成过的攻略存在本地浏览器（最多 50 份），随时翻回
- **连续微调**：结果页直接继续对话，比如"第三天少逛一个景点"、"预算压到 3000"
- **分享导出**：生成链接分享，或下载 Markdown / 打印成 PDF
- **PWA 离线**：可以安装到桌面，离线也能看攻略库

## 技术栈

- Next.js 16 + React 19 + TailwindCSS 4
- AI 生成走的 DeepSeek API（不配置 key 时用内置示例数据，能完整走流程）
- 用户数据存 localStorage，无后端数据库，开发部署都很轻

## 文件结构

```
app/        页面与 API 路由（攻略生成 / 推荐 / 微调 / 历史）
components/ 首页、表单、结果展示等组件
lib/        AI 调用封装、提示词模板、数据存储、容错 JSON 解析
data/       目的地静态数据
public/     图片等静态资源
package.json 依赖与脚本
```
