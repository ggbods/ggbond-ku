# 密码学大作业：基于 Paillier 同态加密的多方安全数据聚合

## 项目简介

场景是：疾控中心想统计多家医院的感染人数总和，但每家医院都不愿意交原始数据。Paillier 加法同态加密正好解决这个问题——各医院用自己的公钥加密数据后上报，疾控中心**不用解密**，直接在密文上相乘做加法，最后解密出来的就是总和，全程碰不到任何一家的原始数据。

本项目把这个方案完整落地，全部从零实现，只用 Python 标准库。

## 实现内容

- `prime_utils.py`：Miller-Rabin 素性检测（40 轮）+ 512 位大素数生成
- `paillier.py`：密钥生成、加密、解密、L 函数、同态加法 / 标量乘法
- `demo.py`：三甲医院聚合场景演示 + 不同密钥位数（256 / 512 / 1024 位）基准测试
- `test.py`：加解密往返、同态性质、素性检测的测试用例

核心难点和解法（过程都写在报告里了）：

1. **模幂中间结果爆炸**：`c**λ mod n²` 直接算不动，改用 Python 内置 `pow(c, λ, n²)`
2. **大整数精度**：除法用 `/` 会变浮点丢精度，必须全部 `//`
3. **Miller-Rabin 逻辑**：用 `for...else` 精确定义"内层没找到 n−1 就是合数"
4. **隐藏 bug**：初版生成素数时 `if 是素数: pass`，检测结果被丢弃导致 p、q 实际是合数，用费马小定理独立验证才发现

## 运行

```bash
python demo.py     # 聚合演示 + 基准测试
python test.py     # 测试用例
```
